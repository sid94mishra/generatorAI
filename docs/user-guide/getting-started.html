Set up GeneratorAI and use it from any device

Install the desktop app, connect your AI accounts, then reach the same app from your phone or another computer on any network. No certificates and no router changes.

00What you need

  • A Mac with Apple Silicon (M1 or later) to run GeneratorAI. This alpha ships as a macOS installer.
  • At least one AI account GeneratorAI can use: Claude, ChatGPT/Codex or GitHub Copilot.
  • A free Tailscale account, only if you want to use GeneratorAI from another device. The free plan covers up to 6 people and unlimited devices.
  • About 10 minutes.

01Install GeneratorAI

1

Open the installer

Double-click GeneratorAI-0.0.1-alpha.1-arm64.dmg, then drag GeneratorAI into Applications.

2

Open it the first time

In Applications, right-click GeneratorAI › Open › Open. The alpha isn't signed by Apple yet, so a normal double-click is blocked the first time.

Still blocked? In Terminal run xattr -dr com.apple.quarantine /Applications/GeneratorAI.app, then open it again.

3

Allow keychain access

macOS asks: "GeneratorAI wants to use your confidential information stored in 'GeneratorAI Safe Storage'". Enter your Mac password and click Always Allow. GeneratorAI keeps its encryption key in your keychain.

Until you answer, the app waits silently. If GeneratorAI seems stuck on launch, look for this dialog behind other windows.

4

You're in

You'll see Home, with Connected at the bottom left.

02First-time setup

1

Connect an AI account

Click the gear at the bottom left › Model providers. Sign in to Claude, ChatGPT/Codex or Copilot. If you already use the Claude Code or Codex command-line tools on this Mac, GeneratorAI picks up those sign-ins.

2

Add a project

Projects › New project. Give it a name and add the folder (or Git repository) you want the AI to work in.

3

Start a chat

On Home, type a task, pick the project, and press ⌘ ↵. GeneratorAI asks before risky actions, such as running commands or pushing code.

That's all you need on this Mac. The next steps are only for using GeneratorAI from another device.

03Set up Tailscale once, on this Mac

Tailscale is a free private network between your own devices. GeneratorAI uses it so your phone or laptop can reach this Mac securely from anywhere, without opening it to the internet.

1

Install Tailscale

Download it from tailscale.com/download (or the Mac App Store) and run the installer.

2

Sign in

Open Tailscale. Its icon appears in the menu bar. If macOS asks, click Allow for the VPN configuration. Choose Log in and sign in with Google, Microsoft, GitHub or Apple.

3

Turn on HTTPS (one click, first time only)

In GeneratorAI: gear › Security & devices › Access from other devices. If the Tailscale card says HTTPS off, click Turn on HTTPS. On the Tailscale page that opens, click Enable HTTPS. Back in GeneratorAI, click the refresh icon on the card. It should now say Ready.

04Turn on access from other devices

1

Click Connect with Tailscale

In Security & devices › Access from other devices, click Connect with Tailscale. After a few seconds the card shows On and your private address, for example https://your-mac.tailXXXX.ts.net.

2

It stays on

It survives quitting and reopening GeneratorAI, and restarting the Mac. It works only while GeneratorAI is running on this Mac.

05Connect your phone or another computer

On the other device

once per device
1

Install Tailscale and sign in with the same account

iPhone and iPad: App Store. Android: Play Store. Windows, Mac and Linux: tailscale.com/download. Make sure Tailscale shows Connected.

On the Mac

2

Create a pairing code

Security & devices › Pair a new device. Type a name (for example "My phone"), pick the platform (Web browser for a browser), and click Generate pairing code. You get the address and a 12-character code, valid for 10 minutes and usable once.

On the other device

3

Open the address

In Safari or Chrome, open the https://…ts.net address shown on the Mac. There's no certificate warning, and the page says Connect to a GeneratorAI server with the address marked Reachable.

4

Enter the code and connect

Type the 12 characters into the code boxes, keep or change the device name, and tap Connect. You're now using GeneratorAI on that device, with your chats, projects and agents.

Keep the code private. Anyone who sees it can pair a device until it's used or expires. Don't screenshot it or paste it into a chat.

06Manage devices

  • See devices: Security & devices › Paired devices lists each device, what it may do and when it was last seen.
  • Remove a device: click Revoke on its row. It loses access straight away and has to pair again with a new code. Other devices aren't affected.
  • Stop all outside access: click Turn off Tailscale access. The address stops working at once. Turn it back on any time with Connect with Tailscale; paired devices keep working.

07Troubleshooting

What you seeWhat to do
GeneratorAI opens but nothing loadsFind the keychain dialog ("GeneratorAI Safe Storage") and click Always Allow.
"GeneratorAI can't be opened"Right-click the app › Open, or run the xattr command from step 1.
Tailscale card: Not installed or Signed outInstall Tailscale or sign in from its menu-bar icon, then click the card's refresh icon.
Tailscale card: HTTPS offClick Turn on HTTPS › Enable HTTPS on the Tailscale page, then refresh.
The address doesn't open on the other deviceCheck Tailscale is Connected on both devices with the same account, and GeneratorAI is running on the Mac.
The address shows "Bad Gateway" (502)GeneratorAI on the Mac isn't running or is still starting. Open it (and answer the keychain dialog).
"Not paired yet" on a device that used to workIt was revoked, or the browser's data was cleared. Pair again with a new code.
Code rejectedCodes expire after 10 minutes and work once. Generate a new one.
Linux: Tailscale says "Access denied"Run sudo tailscale set --operator=$USER once.

08How it works

Your phone or laptopa browser, paired with its own key
→
Tailscale networkencrypted device to device (WireGuard)
→
Tailscale on your Machttps://your-mac…ts.net · trusted certificate
→
GeneratorAIlistens only on this Mac (127.0.0.1)
  • Nothing is opened to the internet. GeneratorAI only listens on the Mac itself. Tailscale forwards to it, and only devices signed in to your Tailscale account can reach the address.
  • No certificate warnings. Tailscale gets a real certificate for your private address from Let's Encrypt, the same kind public websites use.
  • Encrypted twice. Tailscale encrypts traffic between your devices, and the browser adds HTTPS on top.
  • Pairing is still required. Being on your Tailscale network isn't enough. Each device must pair with a one-time code. It then gets its own key that never leaves the device, every request is signed with it, and you can revoke any device on its own.
  • Risky actions still ask. Running commands, pushing code and similar actions need your approval, whichever device you use.
