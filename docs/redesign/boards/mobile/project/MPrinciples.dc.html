Instrument on a phone

The same product as desktop, and the same app on both phones: same sidebar, screens, words and status map. Each platform keeps its own controls, sheets, menus, motion and back gesture.

round 2 · iOS 27 · Android 17
1Same screen on both phones

iOS and Android show the same screen in the same state: same sections, rows, data and actions, in the same place. Only the native language differs: controls, glass vs tonal, type scale, sheets, back.

2A sidebar, not a tab bar

The desktop sidebar is a left drawer: Home, Chats, Projects, Agents, Workflows, Automations, Scripts, then Needs you and Running. Top-level screens show the sidebar toggle top-left.

3Breadcrumbs on detail screens

Detail screens have back plus a 12 px breadcrumb above the title, e.g. Workflows › Nightly dependency audit over “Run #248”. Every segment is tappable.

4The workspace is a right pane

Chat and run screens keep a pane toggle top-right with a count. It slides the desktop dock in from the right: Changes, Files, Terminal, Browser, Tasks, Plan, Computer. Full screen is one tap.

5What needs you comes first

Home leads with three counts (need you, running, finished) and lists each item once with one button. Approvals are a tap on the row, the notification or the chat, never swipe-only. Risky ones ask for Face ID; haptics fire after the server confirms.

6One ink action, one New

Send, Approve or Run is the only filled control. “New” floats bottom-right on both: a glass capsule on iOS, an extended FAB on Android. Status colour never tints a bar.

7Tool calls read as one step

A run of tool calls is one block: “Read 3 files, ran 2 commands, edited 1 file”, with failures and time. It expands in place; a step opens its detail screen.

8Names, not initials

No monogram avatars. A bound agent shows the agents icon and its name; no agent shows the model. Chat rows lead with a status glyph. Your own account is the user icon.

9Chrome floats, content stays flat

Glass only on iOS floating chrome: header buttons, composer, the New capsule, “↓ Latest”. Transcript, lists, drawer and pane content keep borders. Android uses tonal layers.

10Every gesture has a button

Edge swipe opens the sidebar, swipe closes the pane, long-press opens menus: each has a visible control or menu item and a screen-reader action.
