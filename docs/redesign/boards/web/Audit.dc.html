Root cause

The token system — 17 themes × light/dark × 6 accents, contrast-checked — is sound and stays. Nothing above it is shared: each screen was built with its own tabs, menus, status colours and type sizes. Features work; the vocabulary does not.

One component per jobTabs, menus, search, empty and loading states each exist once.
One status mapSeven states, one glyph and colour each; entity kinds stay neutral.
One type scaleSeven sizes from 11 to 28px; nothing smaller, no arbitrary values.
