Checkout E2E suite

Use when a checkout-web Playwright test fails or a new one is needed. The suite runs against a local payments-api with the payment provider mocked.

Run locally

pnpm --filter payments-api dev
pnpm --filter checkout-web test:e2e \
--project=chromium --repeat-each 5

Rules

  • Never add retries to hide a flake; find the race.
  • Seed carts through the API fixtures, not through the UI.
  • Coupon specs assert the total returned by the coupon call.
  • Keep each spec under 30 s; tag slower ones @slow.
