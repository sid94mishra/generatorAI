## Expression v2

### Literals

| Syntax | Meaning |
|---|---|
| `'text' or "text"` | String; escapes \n \t \r \uXXXX \\ \' \" |
| `12, 3.5, -1, 1e3` | Number (only literals can be negative) |
| `true, false` | Boolean |
| `null` | Null |
| `[a, b, 'c']` | List |

### Access and calls

| Syntax | Meaning |
|---|---|
| `a.b.c` | Field access; a missing field or a null value yields null |
| `list[0], list[-1]` | List index, negative from the end; out of range yields null |
| `obj['key']` | Field access by name |
| `name(args)` | Function call; see the function table |
| `x => condition` | Lambda, only as a function argument; x is each element of the list argument |

### Operators (lowest precedence first)

| Syntax | Meaning |
|---|---|
| `or, \|\|` | Logical or (lowest precedence) |
| `and, &&` | Logical and |
| `not, !` | Logical not |
| `== !=` | Strict equality by JSON type, deep for lists and objects |
| `< <= > >=` | Order of two numbers or two strings |
| `x in list, s in text` | List membership or substring |
| `( … )` | Grouping |

### Semantics

| Syntax | Meaning |
|---|---|
| `missing path` | A path through a missing or null value yields null |
| `comparison with null` | Always false (== and != alike); test presence with exists(x) |
| `not null` | null, which counts as false |
| `condition` | Holds only when it evaluates to exactly true |
| `equality` | Strict: '3' == 3 is false (and a type error at save time) |
| `arithmetic` | None; use functions |
| `keywords` | Lower case: and, or, not, in, true, false, null |
| `bounds` | Lists of at most 10,000 elements; 100,000 evaluation steps per expression |

### Roots

| Syntax | Meaning |
|---|---|
| `variables.<name>` | Workflow input variables (typed by their declaration) |
| `stages.<key>.{status, output, summary, attempts, usage}` | Upstream stages only; output is typed from the stage output schema |
| `run.{id, name, codebases.<alias>.{path, branch, baseRef}}` | The run; codebase paths are read-only |
| `parent.status` | The source stage status; edge `when` expressions only |
| `loop.{iteration, number, maxIterations, remaining, carry, priorCarry, operatorInput, usage}` | Inside a loop body and in the loop fields: the current iteration (0-based), its number (1-based), the granted maximum, the carried state, the carry before it, an operator message, the cumulative usage |
| `loop.{last, previous}.{stages.<key>.{output, status, summary}, signals, failures}` | The latest finished iteration and the one before it; null before they exist (see the loop context table) |
| `loop.last.signals.{toolCalls, workspaceChanged, stages.<key>.{toolCalls, outputHash, status}}` | Progress signals of an iteration; a signal that could not be computed is null, never false |
| `loop.history[i].{k, exitValues, signals, usage, score, durationMs}` | Every finished iteration, oldest first |
| `loops.<loopKey>.*` | The same fields of an enclosing loop (nested loops) |
| `item, map, maps, child` | Reserved for map and sub-workflow stages |

### Functions

| Syntax | Meaning |
|---|---|
| `len(list \| string) → number` | Number of elements of a list or characters of a string; null when the argument is null |
| `count(list, x => condition) → number` | Number of elements for which the condition is true; null when the list is null |
| `exists(value) → boolean` | True when the value is not null (a missing path is null) |
| `lower(string) → string` | Lower-cased copy of a string; null when the argument is not a string |
| `at(list, index) → element \| null` | The element at an index; a negative index counts from the end; out of range or a non-integer index yields null |
| `map(list, x => value) → list` | A list of the lambda applied to each element; null when the list is null |
| `filter(list, x => condition) → list` | The elements for which the condition is true, in order; null when the list is null |
| `some(list, x => condition) → boolean` | True when the condition holds for at least one element; false for an empty list, null for a null list |
| `every(list, x => condition) → boolean` | True when the condition holds for every element; true for an empty list, null for a null list |
| `concat(a, b) → list \| string` | Two lists joined, or two strings joined; a null argument counts as empty; null when both are null |
| `unique(list, x => key?) → list` | The list without later duplicates (the first element of each key is kept); the key defaults to the element itself |

| `last(list) → element \| null` | The last element; null for an empty or null list |

## Workflow-run state machine

| From | To | Event | Note |
|---|---|---|---|
| created | starting | `user:start` | idempotent through compare-and-set |
| starting | running | `sys:ready` | every prepare phase settled (workspace, mounts, uploads, preprocessing, sandbox) |
| starting | failed | `sys:setup_error` | status_reason setup:<phase> |
| running | waiting | `sys:idle` | computed after every decision |
| waiting | running | `sys:work_available` |  |
| running | paused | `user:pause` | drain stops launches; interrupt also pauses in-flight instances |
| waiting | paused | `user:pause` | drain stops launches; interrupt also pauses in-flight instances |
| paused | running | `user:resume` | instances paused by the run go to ready |
| running | finalizing | `sys:scope_terminal` | outcome decided; exactly once |
| waiting | finalizing | `sys:scope_terminal` | outcome decided; exactly once |
| paused | finalizing | `timer:pause_ttl` | unattended pause expired; outcome failed |
| finalizing | completed | `sys:finalized` | outcome completed, after onExit and post-processing |
| finalizing | failed | `sys:finalized` | outcome failed (compensation and onFailure ran), or post-processing failed |
