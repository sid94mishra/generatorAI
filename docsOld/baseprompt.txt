High level Functional Requirements: 
- Develop an autonomous agent to create sessions and perform autonomous workflows. 
- User can create a session and configure one or more workflows for the session.
- CRITICAL: User can start multiple sessions at once and should have the ability to interact with each session independently. 
- User can create / pause /play / cancel / delete a session entirely. 
- We will have some predefined workflows. User can attach one or multiple workflows to a session during creation. 
- Every session once created should not start automatically. User has to start the session. ON starting a session if there is an workflows associated with it , then it will be started in sequence. 
- Workflows inside a session will have start / stop / pause buttons. Once workflow paused session paused. This should have a typical parent child relationship between Session and its workflows. 
- For every session user should see all its workflows in sequence and what is started and what is pending.
- Every session will have a chat View where user can send follow up prompts to the Agent. This only be available after the workflows complete for the session. User can cancel the workflows and send prompts. 
- User can send attachments as well as part of prompt context to Agent and then this will be sent to Copilot sdk as attachments for more context. 
- CRITICAL: Session should be persisted. Every user can create multiple sessions and once the application is closed all the session details and workflow details for this need to be saved and next time user should see the progress and all the details for the sessions. 
Every session should store workflow progress and the chat context sent from copilot SDK for persistence and next time user can see and start from that point. 
- CRITICAL: Agent should support a Client / Desktop App for GUI operations. Should have a CLI support for an headless mode. Also Webhook support to trigger any workflows based on external events automatically.

These are the High level functional requirements need to be analyzed before proceeding with architecture planning and implementation planning.
